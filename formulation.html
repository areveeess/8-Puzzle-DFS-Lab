8-Puzzle Problem Formulation

Formal AI state-space modeling, transition dynamics, and reachability invariants.

1. Problem Definition

Classic AI Benchmark

The 8-puzzle is a classic state-space search problem introduced by Sam Loyd in the late 19th century. It consists of a 3×3 square frame containing 8 square tiles numbered 1 through 8, along with one empty space (blank tile, represented by 0). Tiles adjacent to the blank space can slide horizontally or vertically into the empty position. The task is to discover a sequence of valid moves that converts an arbitrary initial state into a designated goal state.

State Representation

A state is formalized as a permutation vector $S = [t_0, t_1, \dots, t_8]$ where each $t_i \in \{0, 1, 2, \dots, 8\}$ and all values are distinct. Index $i$ maps to row $\lfloor i / 3 \rfloor$ and column $i \pmod 3$.

Initial & Goal States

The Initial State is any given starting board permutation. The Goal State is the specified target permutation (e.g., standard canonical order $[1, 2, 3, 4, 0, 5, 7, 8, 6]$ or classical $[1, 2, 3, 8, 0, 4, 7, 6, 5]$).

Actions & Transitions

Operators are defined by the motion of the blank space: Up, Right, Down, or Left. In interior positions, 4 actions are possible; at edges, 3 actions; at corners, 2 actions.

Goal Test & Path Cost

The goal test is an exact equality comparison between the current state array and the goal state array. Every sliding action has a uniform step cost of 1; total path cost equals the number of moves.

2. State-Space Size & Reachability Theorem

Mathematical Proof

Total Permutations: 362,880

Arranging 9 distinct symbols across 9 grid locations yields $9! = 362,880$ total possible board arrangements. However, half of these states can never reach the other half through legal sliding moves.

Reachable State Space: 181,440

Because sliding operations preserve permutation parity, the state space partitions into exactly two disjoint, equal-sized reachability components of 181,440 states ($9! / 2$) each. No sequence of legal moves can cross between components.

Inversion Parity Invariance Principle

An inversion occurs whenever a tile with a higher number precedes a tile with a lower number when reading the board in row-major order (ignoring the blank tile 0):

$$\text{Inversions} = \sum_{i < j, t_i \neq 0, t_j \neq 0} [t_i > t_j]$$

  • Horizontal blank move (Left / Right): Swaps the blank with an immediately adjacent tile. Since the relative order of all numbered tiles remains completely identical, the inversion count does not change ($\Delta \text{inv} = 0$).
  • Vertical blank move (Up / Down): Moves the blank three positions ahead or behind in the linear array. This shifts one numbered tile over exactly two other numbered tiles. As a consequence, the inversion count changes by either $+2$, $0$, or $-2$.
  • Conclusion: In every legal 8-puzzle slide, the parity of the inversion count remains strictly invariant: $\text{inv}(S') \equiv \text{inv}(S) \pmod 2$. An initial state can reach a goal state if and only if their inversion counts have identical parity.
