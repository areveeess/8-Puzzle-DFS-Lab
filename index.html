8-Puzzle Problem Formulation

State-Space Model

State Representation

The 8-puzzle is modeled on a 3×3 grid with 8 uniquely numbered tiles (1 through 8) and one empty blank space (0). Any arrangement is a permutation of the 9 symbols.

State Space & Reachability

The total permutations number 9! = 362,880. Due to sliding motion geometry, the graph partitions into two disjoint components of 181,440 states each based on inversion parity. A valid move preserves parity; initial and goal states must share the same parity to be solvable.

Actions & Transitions

A transition occurs by sliding an adjacent tile into the blank position, equivalent to moving the blank Up, Right, Down, or Left. Border tiles have 2–4 legal moves.

Goal Test & Path Cost

The goal test checks if the current board matches the target configuration. Each move has a uniform step cost of 1; the total path cost equals the move count.

Assigned Algorithm: Depth First Search (DFS)

Register: 24BDS0200 · Raj Vardhan Singh

1. Description

Depth First Search (DFS) is an uninformed graph search algorithm that explores as deep as possible along each branch before backtracking. It is implemented from scratch for this AI assignment using native JavaScript in a background Web Worker.

2. Working Principle

DFS utilizes a LIFO (Last-In, First-Out) stack for its frontier. The most recently discovered state is pushed to the top and expanded next. When a state has no new successors or reaches an already-discovered state, DFS initiates backtracking to the nearest ancestor with unvisited branches. An explicit visited set provides cycle detection to prevent infinite looping.

3. Successor Order

Successors are generated in deterministic order: Up, Right, Down, Left for blank tile movement. This guarantees reproducible search trajectories across runs.

4. Advantages

The primary advantage of DFS is low memory consumption. It only stores the active branch path and unexpanded siblings on the frontier stack, requiring far less RAM than BFS on wide search graphs. If the goal is situated deep along an early branch, DFS can find it quickly.

5. Limitations

DFS can traverse deep unpromising branches before backtracking, making worst-case time high. It is non-optimal and may return an excessively long route even when a short solution exists. Without cycle detection, it can become trapped in infinite loops.

6. Complexity Analysis

Time Complexity: O(b^m), where b is the branching factor (average ~3 in 8-puzzle) and m is the maximum search depth.

Space Complexity: O(bm), linear in maximum depth m because only active branch ancestors and unexplored siblings reside in the frontier stack.

7. Completeness

DFS is complete on finite state spaces when equipped with cycle detection (visited set). Without cycle detection or in infinite graphs, it is incomplete as it may follow infinite paths.

8. Optimality

DFS is non-optimal. It terminates immediately upon discovering any goal path, which depends strictly on tree traversal order rather than minimal step cost.

Analytical Takeaways

  • Uninformed vs. Informed: A* expands only 25 nodes compared to BFS's 152 and DFS's 391, demonstrating the power of Manhattan distance heuristics in focusing search effort.
  • DFS Memory Advantage: DFS maintains low memory ($O(bm)$) even on complex puzzles, while BFS memory explodes exponentially ($O(b^d)$) with solution depth.
  • Optimality Trade-off: DFS discovered a solution of 21 moves, whereas BFS and A* found the optimal 8-move sequence. DFS prioritizes search depth over path length.
