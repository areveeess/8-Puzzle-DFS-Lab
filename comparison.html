In-Depth Analysis & Theoretical Trade-offs

  • Optimality vs. Space (BFS vs. DFS): BFS guarantees an optimal solution of 8 moves because it explores layer-by-layer, but it consumes high memory ($\mathcal{O}(b^d)$) by keeping all frontier nodes in memory. In contrast, DFS required only 12 ms and low memory ($\mathcal{O}(bm)$), but it wandered down a 21-move branch, demonstrating that DFS sacrifices path optimality for linear memory efficiency.
  • Why DLS Failed (Limit = 5): Depth Limited Search with limit $L = 5$ stopped without finding a solution because the shortest path to this goal is at depth $d = 8$. Since $d > L$, DLS is incomplete when the depth limit is set lower than the solution depth.
  • Iterative Deepening (IDDLS): IDDLS resolves the memory dilemma by performing successive depth-limited searches with increasing limits (0, 1, 2, ..., 8). It finds the optimal 8-move solution while maintaining moderate memory consumption, at the cost of expanding 170 nodes and taking 30 ms due to re-expanding early nodes.
  • Greedy Best First Search (GBFS): Using the Manhattan distance heuristic $h(n)$, GBFS aggressively expands nodes with lowest estimated remaining cost. It found an 8-move solution in just 39 expansions and 5 ms, but GBFS in general is neither complete nor optimal.
  • A* Search Superiority: Combining path cost $g(n)$ and admissible Manhattan heuristic $h(n)$ ($f(n) = g(n) + h(n)$), A* expanded only 25 nodes in 4 ms. It achieves the theoretical minimum node expansions while strictly preserving both completeness and optimality.

Heuristic Functions & Domination

Informed search algorithms (GBFS and A*) evaluate node priority using admissible heuristic functions:

Misplaced Tiles Heuristic ($h_1$)

$$h_1(n) = \sum_{i=1}^{8} [tile_i \neq goal_i]$$

Counts tiles out of their goal position (excluding the blank). Admissible ($h_1(n) \le h^*(n)$) and consistent.

Manhattan Distance Heuristic ($h_2$)

$$h_2(n) = \sum_{i=1}^{8} (|x_i - x_{goal,i}| + |y_i - y_{goal,i}|)$$

Sum of grid distances each tile must traverse. Strictly dominates misplaced tiles ($h_2(n) \ge h_1(n)$).
